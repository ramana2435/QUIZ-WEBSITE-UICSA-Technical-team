# Images Folder

Place your main logos and images in this folder.

## Required Files

### 1. **university-logo.png**
- **Description:** Guru Nanak University official logo
- **Recommended Size:** 200x200px or larger
- **Format:** PNG with transparent background
- **Used In:** Header (top left)

### 2. **uicsa-logo.png**
- **Description:** UICSA (University Institute of Computer Science and Applications) logo
- **Recommended Size:** 200x200px or larger
- **Format:** PNG with transparent background
- **Used In:** Header (top right), About UICSA section

### 3. **technical-team-logo.png**
- **Description:** UICSA Technical Team logo
- **Recommended Size:** 200x200px or larger
- **Format:** PNG with transparent background
- **Used In:** Header (top right), Team section

## Optional Files (Team Members)

You can add team member photos here:

- **team-member-1.jpg**
- **team-member-2.jpg**
- **team-member-3.jpg**
- **team-member-4.jpg**

**Recommended Specifications:**
- Size: 400x400px or larger (square)
- Format: JPG or PNG
- The website will automatically crop to circular shape
- Good quality, well-lit photos work best

## Notes

- Use transparent PNG files for logos for best results
- Ensure logos are high resolution for sharp display on all devices
- If an image is missing, the website will gracefully hide it (no broken images)
- File names are case-sensitive on GitHub Pages
